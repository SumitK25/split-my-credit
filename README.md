# SplitMyCredit 💳

A modern React application for smart credit management with stunning glitter credit card animations.

![SplitMyCredit](https://via.placeholder.com/800x400/0063d1/ffffff?text=SplitMyCredit+App)

## ✨ Features

- **Glitter Credit Card** - Beautiful animated credit card with shimmer effects
- **Dual Dashboard** - Separate interfaces for Users and Admins
- **Responsive Design** - Works perfectly on all devices
- **Modern UI** - Clean, professional design with smooth animations
- **Role-based Access** - Secure login for different user types
